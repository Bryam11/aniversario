# Background music

Put the music file here and name it `nuestra-cancion.mp3`.

```text
assets/audio/nuestra-cancion.mp3
```

That is the path already referenced by the `<audio id="bgMusic">` element in
`../index.html`, so no code changes are needed once the file is added.

Supported format: **MP3** (broad mobile support).

> Copyright note: use a track you have the rights to share. If you do not have a
> file yet, the music button will show a friendly hint telling you to add it.
